# miemhpc_challenge_26
MIEM HPC Challenge 2026 - MIEM/HSE

## A. КилоНОД

| Ограничение времени   | 10 секунд                         |
|-----------------------|:----------------------------------|
| Ограничение памяти    | 128 Мб                            |
| Ввод                  | стандартный ввод или input.txt    |
| Вывод                 | стандартный вывод или output.txt  |

Даны два целых числа a и b. Найдите их наибольший общий делитель (НОД).

### Условия
Числа помещаются в 64-х битный знаковый целый тип. Гарантируется, что оба числа не равны нулю одновременно.

### Формат ввода
В единственной строке через пробел заданы два целых числа a и b.

### Формат вывода
Выведите одно целое число gcd(a, b) — наибольший положительный общий делитель a и b.

## B. Просто простые числа

| Ограничение времени   | 10 секунд                         |
|-----------------------|:----------------------------------|
| Ограничение памяти    | 128 Мб                            |
| Ввод                  | стандартный ввод или input.txt    |
| Вывод                 | стандартный вывод или output.txt  |

Даны границы L и R. Требуется вывести все простые числа в интервале [L, R], по одному в строке, в порядке возрастания.

### Формат ввода
Одна строка содержит два целых числа L и R, разделённых пробелом.

### Формат вывода
Выведите все простые p, такие что L ≤ p ≤ R, разделённые пробелами. Если в интервале нет простых чисел, выведите −1.

## C. ЭксаКарта

| Ограничение времени   | 10 секунд                         |
|-----------------------|:----------------------------------|
| Ограничение памяти    | 128 Мб                            |
| Ввод                  | стандартный ввод или input.txt    |
| Вывод                 | стандартный вывод или output.txt  |

На плоскости заданы n городов с координатами $`(x_i, y_i)`$. Расстояние между городами i и j — евклидово: 
$`d(x_i, y_i), (x_j, y_j)`$ = $`\sqrt{(x_i − x_j)^2 + (y_i − y_j)^2}`$.
Необходимо найти минимальную длину гамильтонова цикла, посещающего все города ровно по одному разу и возвращающегося в начальный город.

### Формат ввода
Первая строка содержит целое число n(2 ≤ n ≤ 18). Следующие n строк содержат по два целых числа $`x_i,y_i`$. Гарантируется, что все города имеют различные координаты.

### Формат вывода
Выведите одно вещественное число — минимальную длину цикла. Ответ выведите с абсолютной погрешностью не более 
$`10^{−6}`$.

## D. МегаСортировка

| Ограничение времени   | 10 секунд                         |
|-----------------------|:----------------------------------|
| Ограничение памяти    | 128 Мб                            |
| Ввод                  | стандартный ввод или input.txt    |
| Вывод                 | стандартный вывод или output.txt  |

Дан огромный файл, содержащий n 32-битных беззнаковых целых чисел. Объём файла превышает объём доступной оперативной памяти. Вам необходимо отсортировать числа по возрастанию и вывести результат в новый файл.

### Формат ввода
Во входном файле на первой строчке написано число n — размер сортируемого массива. Далее на второй строчке через пробел записаны числа, которые необходимо отсортировать.

### Формат вывода
Выходной файл должен содержать числа, записанные через пробел в порядке возрастания.
